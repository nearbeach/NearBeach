Api Specific Information
========================

For all documentation on API Points and Schema shapes, please visit our Swagger documentation - https://swagger.nearbeach.org

Authentication
==============

The API accepts a logged in session, a ``Token`` (Knox) header, an OAuth2 ``Bearer`` token, or HTTP Basic (not for
users with two-factor authentication). To let another system
call the API, see :ref:`oauth2-api`.
